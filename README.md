# GENTV

App per Android TV / Google TV / Fire TV.

## Installazione
Scarica l'ultima versione: [GENTV.apk](https://github.com/francescotep-ai/GENTV/releases/latest/download/GENTV.apk)

Su Fire TV / Android TV puoi usare l'app **Downloader** e inserire il codice indicato dall'amministratore.

Accedi con il nome utente e la password che ti sono stati forniti.
